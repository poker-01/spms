# 🏢 智慧物业管理系统 (Smart Property Management System)

> 基于 Spring Boot 3 + Vue 3 的智慧物业管理系统 

---

## 📋 项目简介

本项目是一个面向小区物业管理的 Web 应用系统，包含业主管理、报修管理、费用账单、停车管理、投诉建议、公告通知等核心功能模块。

---

## 🛠 技术栈

### 后端
| 技术 | 版本 | 说明 |
|------|----|------|
| Java | 21 | 开发语言 |
| Spring Boot | 3.x | 核心框架 |
| Spring Security | 3.x | 认证与权限 |
| MyBatis-Plus | 3.x | ORM 框架 |
| MySQL | 8.0 | 数据库 |
| Maven | 3.8+ | 项目构建 |

### 前端
| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.x | 前端框架 |
| Vite | 4.x | 构建工具 |
| Element Plus | 2.x | UI 组件库 |
| Axios | 1.x | HTTP 请求 |
